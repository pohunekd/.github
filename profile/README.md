**pohunek** is a headless, multihost backbone for coding agents: one small
daemon per machine, one durable terminal per agent session, and one versioned
JSON contract for everything built on top. The agent is the user. You are the
owner who hears about it when a session needs you.

A *pohunek* is the farmhand boy who drives the draft animals. He does not plow
himself.
